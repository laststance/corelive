# CoreLive

CoreLive organizes writing and completed work by category.

## Language

**LiveEditor**: The notepad in the CoreLive macOS app where a user writes and completes lines.

**LiveEditor draft**: The current text for one category in LiveEditor. Adding a task appends an unfinished line to this draft.

**Completed task**: A record of one task completion in a category. Completing two tasks with the same title produces two entries in the completion history.
